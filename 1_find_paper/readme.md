实现功能：

输入：论文

输出：

| 维度      | Agent 应回答的问题          | 产物            |
| ------- | --------------------- | ------------- |
| 1. 基本信息 | 谁、什么时候、哪里发表？          | Metadata      |
| 2. 研究问题 | 为什么要做？解决什么问题？         | Problem       |
| 3. 核心贡献 | 相比已有工作新增了什么？          | Contributions |
| 4. 方法   | 方法具体怎么工作？             | Method        |
| 5. 实验   | 数据、baseline、指标、设置是什么？ | Experiments   |
| 6. 结果   | 到底提升多少？在哪些情况下有效？      | Results       |
| 7. 局限性  | 什么没解决？什么条件下可能失败？      | Limitations   |
| 8. 研究启发 | 能从这里继续研究什么？           | Gaps / Ideas  |
